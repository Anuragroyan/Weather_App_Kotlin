🌤️ Weather Dashboard

Weather Dashboard is a Kotlin-based Android application that provides detailed and location-specific weather information through a clean and modern dashboard. The application fetches live weather data from the OpenWeatherMap API and presents important weather parameters in an easy-to-understand format.

Using Retrofit for API communication, the app retrieves weather information for a selected location and displays details such as weather conditions, wind speed, humidity, precipitation, wind direction, sunrise, and sunset timings.

✨ Features

* 🌍 Location-Based Weather – View weather information for a selected location.
* 🌡️ Weather Conditions – Display current weather conditions and related information.
* 💨 Wind Speed – Show the current wind speed.
* 🧭 Wind Direction – Display wind direction in degrees.
* 💧 Humidity – Show the current humidity level.
* 🌧️ Precipitation – Display available precipitation information.
* 🌅 Sunrise Time – Show the expected sunrise timing.
* 🌇 Sunset Time – Show the expected sunset timing.
* 🔄 Live API Data – Fetch weather information from OpenWeatherMap.
* 🌐 Retrofit Integration – Handle REST API communication efficiently.
* 🎨 Weather Dashboard UI – Present multiple weather parameters in an organized dashboard.
* 📱 Jetpack Compose UI – Build the modern Android interface using Compose.

🛠️ Tech Stack

* Kotlin
* Android
* Jetpack Compose
* Retrofit
* OpenWeatherMap API
* REST API
* JSON
* AndroidX

🎯 Project Purpose

The project demonstrates how to build a practical Android weather application using Kotlin, Jetpack Compose, Retrofit, and a third-party REST API. It focuses on API integration, JSON data handling, asynchronous data retrieval, and presenting multiple real-time weather parameters through a clean dashboard interface.
